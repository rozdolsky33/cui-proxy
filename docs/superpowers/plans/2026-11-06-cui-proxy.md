# cui-proxy Implementation Plan

> Historical design/implementation record. Its original status and checklists
> describe that work, not the current release. For implemented settings and
> behavior, see [configuration](../../configuration.md) and
> [documentation status](../../documentation-status.md).


> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Go binary that runs as a local proxy for Codex CLI, replaces restricted values in outbound requests with realistic synthetic ones, restores them in responses, and serves a localhost dashboard.

**Architecture:** `harness -> proxy -> adapter (finds text fields) -> detectors (find spans) -> vault/synth (replace) -> upstream`; the response stream goes back through the adapter and a streaming restorer. Adapters, detectors and generators are registered behind small interfaces so new harnesses and rules are additions, not core edits.

**Tech Stack:** Go 1.26, standard library (`net/http`, `net/http/httputil`, `embed`, `crypto/hmac`, `crypto/aes`), `gopkg.in/yaml.v3` (only third-party dependency; YAML config is required by the spec and the stdlib has no YAML). Plain HTML/JS for the UI. Lint: `go vet`, `staticcheck`.

**Spec:** `docs/superpowers/specs/2026-11-06-cui-proxy-design.md` (section 13 holds the post-review decisions). Spike findings: `docs/spikes/2026-11-06-codex-redirect-spike.md`. Read both.

## Global Constraints

- Go module name `cui-proxy`; single static binary; macOS arm64 primary, Linux amd64 secondary.
- Standard library preferred; every dependency justified (only `yaml.v3` approved).
- Proxy and UI bind to loopback only; refuse a non-loopback `listen`/`ui.listen` unless config sets `allow_non_loopback: true`.
- Default `policy.on_error: block` (fail-closed); default `policy.max_body_bytes: 20MiB`.
- Real values never appear in logs, the UI, metrics, audit events or panic output. Only rule names, counts, and fingerprints (first 8 hex chars of SHA-256 of the value).
- Auth headers (`Authorization`, `Chatgpt-Account-Id`, cookies) pass through untouched and are never logged or stored.
- Synthetic values come from reserved ranges (RFC 5737 / RFC 3849 IPs, `.example` / `.invalid` hostnames) so they can never be real external values.
- Vault is in-memory by default; file mode is encrypted (AES-256-GCM) with a key file at user-only permissions (0600).
- Tests: `go test -race ./...`, `go vet ./...`, `staticcheck ./...` must pass at the end of every task.
- Commits end with the trailer line: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Failure modes the spec implies that no task's headline tests would catch. Each has a pinning test in the owning task (marked **[RF]**).

1. Synthetic value already in history: detectors match reserved-range synthetics (e.g. `192.0.2.5` is a valid IPv4). They must NOT be re-pseudonymized on the next turn. (Task 4)
2. A value split across SSE delta chunks at any byte boundary, including inside JSON escapes or multibyte UTF-8. (Tasks 4, 6)
3. Compressed request bodies (`Content-Encoding` set): cannot be scanned, so they must be blocked, and upstream responses must be requested uncompressed so SSE can be rewritten. (Task 8)
4. Upstream non-200 responses and client disconnects mid-stream: error bodies pass through, nothing hangs, no goroutine leak. (Task 8)
5. Values hidden by JSON escaping (`.`, `\"`) in `arguments` strings and tool output: scan decoded strings, re-encode correctly, never produce invalid JSON. (Task 6)

### Task 8: Reverse proxy

**Files:**
- Create: `internal/proxy/proxy.go`, `headers.go`, `proxy_test.go`

**Interfaces:**
- Consumes: `adapter.Adapter`, `transform.Sanitizer/Restorer`, `sse`, `metrics.Registry`, `audit.Log`, `config.Config`
- Produces:
  ```go
  package proxy
  type Deps struct { Cfg *config.Config; Adapter adapter.Adapter; Upstream *url.URL; Sanitizer *transform.Sanitizer; Restorer *transform.Restorer; Metrics *metrics.Registry; Audit *audit.Log; Transport http.RoundTripper }
  ```

### Task 10: CLI, wiring and hot reload

**Files:**
- Create: `cmd/cui-proxy/main.go`, `serve.go`, `check.go`, `rules.go`, `app.go`, `app_test.go`, `examples/config.yaml`, `examples/hosts.txt`, `README.md`

**Interfaces:**
- Consumes: everything above.
