# Task 05: protocol and task semantics

Task 05 qualifies representational correctness for the existing Codex Responses
adapter. It does not expand its protocol allowlist or claim model equivalence.

## Contract

Maintain a support matrix with executable evidence for routes, transports,
request items, attachment positions, response events and session boundaries.
Clearly distinguish restored content, opaque passthrough and rejected forms.

Exercise repeated full histories and delegated tool context, visible summaries
beside encrypted compaction, and fresh response rewriters after interruption.
A reconnect means a new complete response stream: arbitrary suffix continuation
and server-side replay/deduplication are not supported promises.

Verify restored command arguments by executing an isolated, fixed local command;
verify files and configuration by inspecting resulting bytes and parsed values.
Cover quotes, backslashes, Unicode, large integers, decimals and exponent forms.
No network or model process is used by these deterministic tests.

Add an offline paired-live outcome summarizer with independent direct/proxy
results, separating model outcome differences from transport/proxy failures.
It must reject incomplete pairs and report denominators. Live execution requires
an authorized backend and is not a prerequisite for deterministic evidence;
without live samples the model-quality result is explicitly unmeasured.

## Safety

Use synthetic inputs only. Capture test output privately. Do not weaken
fail-closed policy, add transport claims, or send paid provider requests.
